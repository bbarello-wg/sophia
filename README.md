## Client Alignment

My design choices support the client’s goals by keeping the website simple, easy to navigate, and readable. The navigation menu is displayed horizontally so users can quickly move between the Home, Product, About, and Contact pages. The layout is also kept clean so visitors can focus on the main content without unnecessary distractions.

## Color Palette

The main colors used in the website are **black, blue, red, and white**.

- **Black** is used for the main body text because it is easy to read against a white background.
- **Blue** is used for the main headings to help important information stand out.
- **Red** is used for paragraph text to create contrast and add visual interest.
- **White** is used for the background to keep the overall design clean and readable.

## Typography

I used **Verdana** for the main headings and **Courier** for paragraph text.

Verdana is easy to read and works well for headings because it has a clean and bold appearance. Courier gives the paragraph text a different visual style and helps separate the body content from the headings.

Using two different fonts also creates a clear visual hierarchy between headings and regular text.

## Responsive Design

The website uses responsive design so images and videos adjust to different screen sizes.

Images have a maximum width of **100%** on larger screens so they do not overflow their containers.

On screens that are **600 pixels wide or smaller**, images are reduced to **70% width** and centered on the page. Videos are also reduced to **75% width** and centered on smaller screens.

These changes help the content fit more comfortably on mobile devices.

## Design Challenge

One design challenge I encountered was making large images and videos display properly on mobile devices. At their original size, they could take up too much space on smaller screens and make the page harder to view.

I addressed this problem by adding a media query for screens **600 pixels wide or smaller**. Inside the media query, I reduced the image width to **70%** and the video width to **75%**, then centered both using automatic margins.

This improved the mobile layout and made the media easier to view.
